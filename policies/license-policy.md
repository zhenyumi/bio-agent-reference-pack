# License Policy

This repository must record license and redistribution status before upstream source files are vendored.

Full text can only be vendored when redistribution is permitted. Copyrighted PDFs, copied books, copied articles, and copied documentation must not be added unless the license review explicitly allows it.

Agents must not invent license metadata. If the license is unknown, record it as unknown or planned and request review before acquisition.

Public URLs, public citation metadata, and links to official documentation may be recorded when appropriate.
