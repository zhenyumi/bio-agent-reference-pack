# Conflict Resolution

When sources conflict, agents must not invent methods or reconcile disagreements by preference.

Process:

1. Identify the conflicting source IDs and exact upstream locations.
2. Apply `policies/source-priority.md`.
3. Prefer package-version-specific official documentation for code behavior in a project using that package version.
4. Preserve downstream project constraints when they are explicit.
5. Record the conflict and request higher-level review when priority or interpretation remains unclear.

Indexes may point to the conflicting sources, but they must not resolve scientific disagreements by summarizing or rewriting guidance.
