# Source Priority

When sources conflict, agents must use this order unless a reviewed project-specific policy says otherwise:

1. Downstream project `AGENTS.md`, `PLAN.md`, existing scripts, and previous outputs
2. Dataset paper, supplementary methods, and author code
3. Official package documentation for the package version in use
4. OSCA, OSTA, and sc-best-practices
5. Peer-reviewed method papers
6. Tutorials, blogs, and examples only as secondary aids

Agents must not invent source priority. If the correct priority is unclear, stop and request higher-level review.
