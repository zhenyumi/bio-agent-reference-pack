# Privacy and Git Hygiene

The repository must not commit:

- API keys, tokens, passwords, credentials, or certificates
- Proxy addresses or private server URLs
- Local absolute paths or home directories
- IP addresses or private network locations
- Private locations or machine-specific configuration
- Raw PDFs, large archives, or downloaded full text unless explicitly approved after license review
- Local caches, logs, temporary outputs, IDE state, or local-only overrides

Acceptable public metadata includes:

- Public author names
- Public institutional affiliations
- Public citation metadata
- Public URLs
- Public package names and versions

`PLAN.md`, `AGENTS.md`, `.codex/`, and `.opencode/` are intentionally version-controlled.
