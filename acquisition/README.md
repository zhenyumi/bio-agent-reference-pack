# Acquisition Review Packages

Files in this directory are acquisition review packages only.

They are not authoritative source metadata. They collect candidate upstream URLs,
candidate license evidence URLs, and uncertainty notes for Codex review.

Codex must review before any of the following change:
- references.yaml
- sources.lock.yaml
- sources/upstream/

No source in this directory has been acquired. No license status is final.
All redistribution risk assessments are preliminary and pending Codex review.

Candidate URLs are classified as:
- verified official candidate: well-known public page for the project
- unverified candidate requiring Codex review: source repo or secondary URL
  not confirmed from the official page's own links
